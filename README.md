# Ход за Ходом — прокат настольных игр и антикафе

Учебный лендинг: один HTML, один CSS, один JS. Без фреймворков, без сборки,
без сторонних библиотек. Вся графика нарисована вручную — inline SVG и CSS,
ни одного растрового файла.

```
index.html   разметка + SVG-спрайт со всеми иллюстрациями
style.css    оформление, сетки, анимации, адаптив
app.js       параллакс, кубик, счётчики, reveal, модалка, формы
img/         фотографии зала и полки (7 файлов, ~800 КБ)
```

Открыть: двойной клик по `index.html`. Сервер не нужен.


## Что нового

### Каталог «Шесть игр для старта»
- Шесть игр: Catan, Codenames, Dixit, Avalon, Ticket to Ride, Munchkin.
- У каждой — своя **SVG-иллюстрация**, попадающая в суть игры (гексы с разбойником,
  сетка 5×5 с чёрной картой, кролик в шляпе, круглый стол с мечами и щитами,
  вагончики между городами, меч-шлем-сапоги-монеты).
- Описание на 2–3 предложения (игроки, время, возраст, «о чём игра») и теги-чипы.
- Клик по карточке раскрывает панель с деталями (аккордеон внутри карточки),
  кнопка «Забронировать» подставляет название игры в модалку.
- «Бросить кубик»: SVG-кубик крутится, меняет грани, падает на выпавшее значение,
  случайная игра подсвечивается и раскрывается.

### Анимации и интерактив
- `IntersectionObserver` показывает секции при скролле; карточки каталога
  «вылетают» друг за другом по 80 мс, линия дорожки в «Как играем» рисуется
  слева направо.
- Hover: карточка приподнимается, иллюстрация увеличивается до `scale(1.03)`,
  кнопки вдавливаются, клетки навигации слегка поворачиваются.
- Фишка в hero прыгает по клеткам дорожки (синусоидальный «подскок» на каждый шаг),
  затем страница плавно уезжает к услугам.
- Счётчики в hero (150 ₽ / 418 / 2 часа) анимированно набегают при первом появлении.
- Параллакс: миплы, кубики и звёзды летят с разной скоростью (`data-depth`).
- Модалка появляется с масштабированием от `0.95` и лёгким поворотом.
- Курсорное световое пятно на карточках (только `hover:hover` + `pointer:fine`).

### Секция «Не только прокат — антикафе» (§3)
- Формат: 3 ₽/минута, напитки включены, 418 коробок или своя игра, администратор
  поможет с правилами.
- Три тарифа: Час — 180 ₽, Три часа — 450 ₽ (−15%), День — 900 ₽.
- Галерея зала из шести квадратных SVG: большой зал, уголок для двоих,
  полки с играми, чайная зона, мягкая зона, сцена для турниров.
- Расписание событий (Пн–Вс) таблицей; на мобильных таблица превращается
  в стопку карточек.
- Кнопка «Забронировать столик» открывает модалку сразу на вкладке «Антикафе».

### Формы
- Модалка получила две вкладки: «Прокат» и «Антикафе» (стрелки ←/→ работают).
- Маска телефона `+7 (999) 123-45-67` на всех полях `type="tel"`.
- Select «Что интересует» в записке: прокат / антикафе / пятничная игротека / другое.
- Ошибка — поле трясётся 300 мс; после успешной отправки записка переворачивается
  и показывает благодарность, поверх мелькает штамп «Отправлено!» (2 с).

## Как устроена графика

**Спрайт.** В начале `<body>` лежит один скрытый `<svg class="sprite">` со всеми
`<symbol>`. В разметке они подключаются так:

```html
<svg class="art" viewBox="0 0 400 400" role="img" aria-label="Иллюстрация к игре Catan">
  <use href="#game-catan"></use>
</svg>
```

Префиксы id:

| Префикс | Что это |
|---|---|
| `game-` | иллюстрации игр каталога (`game-catan`, `game-codenames`, `game-dixit`, `game-avalon`, `game-ticket`, `game-munchkin`) |
| `hall-` | галерея антикафе (`hall-big`, `hall-two`, `hall-shelf`, `hall-tea`, `hall-soft`, `hall-stage`) |
| `about-shelf` | «фото» зала в секции «О нас» |
| `dec-` | декор: кубик, пешка, звезда (параллакс, логотип, фишка) |
| `dice-faces` | кубик d6: все шесть граней отдельными группами `data-f="1..6"` |

**Стиль.** Обводка — 2–2,5 px фирменными чернилами, плоские заливки только из
палитры, скруглённые концы линий и лёгкие наклоны: за счёт этого рисунок
выглядит нарисованным от руки. Никаких `<image>`, градиентов внутри SVG и
внешних ассетов.

**Палитра внутри SVG задана классами, а не атрибутами.** Это важно: `<use>`
отрисовывает фигуры через shadow-дерево, куда доезжают унаследованные
CSS-свойства, но не значения вида `fill="var(--burgundy)"`. Поэтому в разметке
используются классы:

| Класс | Что задаёт |
|---|---|
| `fc-ink`, `fc-burg`, `fc-must`, `fc-kraft`, `fc-paper`, `fc-paper2`, `fc-felt`, `fc-sage` | `fill` из соответствующей переменной `:root` |
| `sc-ink` и остальные `sc-*` | `stroke` из переменной |
| `fill="#4a6fa5"` и подобные | редкие оттенки палитры, которых нет в переменных |

Правила живут в начале `style.css`, поэтому цвет меняется в одном месте.

**Кубик.** Каждая грань — отдельная группа `data-f="1..6"` внутри символа.
Грань переключается атрибутом `hidden` на этих группах: `<use>` отрисовывает
их живую теневую копию, поэтому изменение атрибута в спрайте сразу меняет
картинку, а вот селекторы и inline-стили до копии не достают. JS во время
броска перебирает грани, а в конце оставляет выпавшую — и на большом кубике,
и на иконке в кнопке.

**CSS-графика.** Гексы каталога — `clip-path`, а обводка гекса — фильтр
`drop-shadow` с нулевым сдвигом (вписанный внутрь гекс на вершинах расползался
в широкую полупрозрачную полосу и карточка выглядела серой). Скотч на записке —
полупрозрачный прямоугольник с поворотом и тенью, стрелка `<select>` — два
`linear-gradient`, линия дорожки — `repeating-linear-gradient`, фон-бумага —
набор радиальных градиентов и точечный паттерн.

## Доступность и адаптив

- Семантика: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`,
  `<form>`, `<table>` с `<caption>`, `<footer>`; все кнопки — `<button type="button">`.
- Карточки игр фокусируются, раскрываются Enter/Space; модалка держит фокус (Tab),
  закрывается Escape, возвращает фокус на элемент-источник.
- Видимый фокус: `outline` 3px, на зелёном сукне — горчичный.
- Тексты в JS пишутся только через `textContent`, `innerHTML` не используется.
- Брейкпоинты: 1180 / 960 / 768 / 620 / 380 px. Гекс-пирамида 3-2-1 на десктопе,
  две колонки на планшете, скруглённые карточки в одну колонку на телефоне.
- `prefers-reduced-motion: reduce` отключает все переходы и анимации: счётчики
  показывают конечные числа, секции сразу видимы, фишка не прыгает.

## Что проверено в браузере

Страница открывалась headless-Chrome напрямую через `file://` и с локального
сервера, на ширинах 1440 / 1280 / 980 / 900 / 760 / 700 / 520 px. В каждой
секции сверялись вычисленные стили и цвета пикселей:

- заливка гексов — `rgb(253, 246, 231)` (кремовая бумага), обводка 2 px;
- точки кубика видны на всех шести гранях и на иконке в кнопке;
- клик по «Бросить кубик» показывает кубик, выводит «Выпало N. <Игра>»
  и раскрывает панель выбранной карточки;
- горизонтальной прокрутки нет ни на одной ширине;
- `node --check app.js` — без ошибок; скобки в `style.css` сбалансированы
  (434 / 434), `innerHTML` в JS не используется, `style="…"` в разметке нет.

### Что было починено после проверки

1. **У кубика не было точек.** `<use>` рисует фигуры через shadow-дерево, и ни
   селекторы, ни inline-стили до него не достают. Теперь грани — отдельные
   группы в спрайте, а переключаются они атрибутом `hidden`; точки получили
   класс `pip-live`, чтобы не зависеть от порядка правил.
2. **Карточки каталога выглядели серыми.** Обводка рисовалась вторым гексом,
   вписанным внутрь на 2 px, но у вершин такая линия расширялась до 4–5 px и
   превращалась в широкую полупрозрачную полосу. Обводка заменена на
   `drop-shadow` с нулевым сдвигом — ровные 2 px по контуру.
3. **На планшете карточка уезжала влево за экран.** У гекс-сетки была
   фиксированная ширина карточки и `justify-content: center`: когда треки
   становились шире вьюпорта, вся сетка центрировалась и крайняя карточка
   уходила за границу. Теперь ширину задаёт контейнер, сетка не центрируется.
4. **Линия дорожки в «Как играем»** проходила на 24 px, то есть у самого края
   карточек, и читалась как случайная полоска. Дорожка вынесена над карточками,
   по верхушкам номеров, и получила точки-клетки.
